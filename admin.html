🏆 Programme de fidélité

Si désactivé, aucune réduction fidélité n'est appliquée. Vous fixez les seuils et les % ci-dessous.

Pour le système VIP (VIP1→VIP4), choisissez Argent dépensé et mettez des seuils en € (ex : Argent 10, Or 50, Diamant 150).
👑 Niveaux VIP (VIP1 → VIP Max)
Les coupons ×N du client se rechargent selon cette période.
Ex : 500 XOF dépensés = +20 EXP. Les seuils EXP ci-dessous déterminent le passage de niveau.

💳 Méthodes de paiement (ouvrir / fermer)

Décochez pour masquer une méthode chez les clients.

🟠 CinetPay (Orange Money Mali) — collez votre Site ID et votre API Key CinetPay. La méthode apparaît automatiquement chez les clients une fois les deux remplis. Ce sont des identifiants publics du widget CinetPay — ne collez jamais ici une clé secrète serveur.

💠 MoneyFusion (Orange Money · MTN · Wave · Moov · carte) — cochez MoneyFusion dans la liste ci-dessus pour l'activer chez les clients.

🔧 Configuration dans Vercel → Settings → Environment Variables :
• MONEYFUSION_API_URL = votre lien d'API MoneyFusion
• PUBLIC_BASE_URL = https://mgloot.com

Le webhook est envoyé automatiquement à https://mgloot.com/api/moneyfusion dans chaque transaction.

Après paiement, le portefeuille / la commande du client est crédité(e) automatiquement (côté serveur, sécurisé).
